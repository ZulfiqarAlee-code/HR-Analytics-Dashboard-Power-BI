# 📊 HR Analytics Dashboard — Power BI

## 📌 Project Overview


This project presents an interactive **HR Analytics Dashboard built using Microsoft Power BI**.

The objective is to transform raw employee data into meaningful HR insights that can help understand workforce composition, employee attrition, salary patterns, job satisfaction, and other important workforce metrics.

The project demonstrates an end-to-end Power BI workflow:

**Raw Data → Data Cleaning → Data Transformation → DAX → KPI Development → Data Visualization → Interactive Dashboard → Business Insights**

---

## 🎯 Business Objective

The dashboard is designed to answer important HR-related questions such as:

* How many employees are currently in the organization?
* What is the employee attrition rate?
* How is the workforce distributed across departments?
* What is the gender distribution?
* Which age groups contain the most employees?
* How does salary vary across employees?
* What are the major patterns in employee satisfaction?
* How does experience relate to employee attrition?
* What workforce trends can HR teams identify from the data?

## 🔄 Project Workflow

### 1. Data Import

The HR dataset was imported into Power BI for analysis.

### 2. Data Cleaning & Transformation

Power Query was used to prepare the dataset for analysis, including:

* Handling missing/null values
* Removing duplicate records where required
* Correcting data types
* Cleaning inconsistent values
* Preparing fields for analysis

### 3. Data Analysis

The employee dataset was analyzed across multiple HR dimensions, including:

* Employee demographics
* Department
* Gender
* Age
* Experience
* Salary
* Attrition
* Job satisfaction

### 4. DAX & KPI Development

DAX measures were created to calculate important HR metrics and support interactive analysis.

Examples include:

* Total Employees
* Attrition
* Attrition Rate %
* Average Salary
* Employee distribution metrics
* Department-level metrics

### 5. Dashboard Development

Interactive Power BI visuals were created using:

* KPI Cards
* Bar Charts
* Donut/Pie Charts
* Slicers
* Filters
* Other analytical visuals

The dashboard allows users to interact with the data and explore different employee segments.
